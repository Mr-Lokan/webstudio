Полная версия работает при локальном запуске

На GitHub Pages размещена статическая копия публичной части сайта: услуги, портфолио, калькулятор и информация о студии. Регистрация, вход, личный кабинет клиента, оформление заказов, обратная связь и панель управления (CRM) требуют сервера с Python и базой данных SQLite.

Как запустить

  1. Скачайте исходный код: github.com/Mr-Lokan/webstudio → Code → Download ZIP.
  2. Установите Python 3.10 или новее.
  3. В папке проекта выполните pip install -r requirements.txt.
  4. Запустите python run.py (или start.bat в Windows).
  5. Откройте http://127.0.0.1:5000.

База данных с демонстрационными данными создаётся автоматически при первом запуске.
