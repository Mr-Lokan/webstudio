# WebCraft — информационная система студии веб-дизайна

Курсовой проект по дисциплине «Web-технологии» на тему «Автоматизация студии веб-дизайна».

**Демо-версия сайта: https://mr-lokan.github.io/webstudio/**

На GitHub Pages сайт работает полностью: то же Flask-приложение запускается прямо в браузере посетителя
через Pyodide (Python в WebAssembly). Работают регистрация, вход, личный кабинет, заказы и панель
управления (демонстрационные учётные записи - ниже). Данные каждого посетителя хранятся только в его
браузере, сбросить их можно ссылкой в подвале сайта. Первый запуск приложения занимает несколько секунд.

## Возможности

**Публичная часть сайта**
- главная страница, каталог услуг с фильтром по категориям, карточка услуги;
- портфолио с фильтром и страницами проектов;
- калькулятор стоимости проекта с передачей расчёта в форму заказа;
- страница «О студии» с командой, форма обратной связи.

**Личный кабинет клиента**
- регистрация и вход (пароли хранятся в виде хеша);
- оформление заказа, список заказов со статусами и оплатами;
- переписка с исполнителем, история статусов;
- приёмка работы или возврат на доработку, отзыв о выполненном заказе;
- редактирование профиля и смена пароля.

**Панель управления (CRM)**
- дашборд: выручка по месяцам, заказы по статусам, загрузка дизайнеров, просроченные заказы;
- заказы: поиск и фильтры, назначение исполнителя, стоимости и срока, смена статуса, платежи, переписка;
- экспорт реестра заказов в CSV (Excel);
- управление услугами, категориями, портфолио (с загрузкой изображений), пользователями и ролями;
- обработка обращений и модерация отзывов.

Роли: **администратор** (полный доступ), **дизайнер** (только назначенные ему заказы), **клиент**.

## Запуск

Требуется Python 3.10+.

```
pip install -r requirements.txt
python run.py
```

или двойной щелчок по `start.bat`. Сайт откроется по адресу http://127.0.0.1:5000

При первом запуске автоматически создаётся база данных `instance/studio.db` с демонстрационными данными.
Пересоздать базу: удалить файл `instance/studio.db` или выполнить `flask --app run init-db`.

## Версия для GitHub Pages

GitHub Pages не запускает Python, поэтому сайт для Pages собирается в папку `docs/`:

- публичные страницы заранее отрисованы в HTML и открываются сразу;
- приложение упаковано в `docs/pyapp/app.zip` и запускается в браузере через Pyodide (`docs/pyodide`);
- `pages/runtime.js` перехватывает переходы и формы и передаёт их приложению, `pages/webapp.py` -
  обвязка Flask внутри браузера, `pages/wheels/` - пакеты Flask для Pyodide;
- база SQLite и загруженные изображения хранятся в IndexedDB браузера, начальные данные берутся из
  `instance/studio.db` на момент сборки.

Пересобрать после изменений:

```
python build_pages.py
```

После коммита и отправки изменений на GitHub сайт обновится автоматически
(Settings → Pages: ветка `main`, папка `/docs`).
